# Creation and verification method

Start with the corporate use case, languages and brand character. Compare three small concepts using identical real text; develop only the chosen direction. Draw original outlines from the author's own geometry and masters. References guide the impression, not outline extraction. Mono/Code developments use the author's Sans/Mono drawing source.

Establish regular text rhythm before expanding weights and italics. Use fixed A4 and web proof text. Compare at the same sizes, measure actual curve extrema, and check words and paragraphs instead of isolated glyphs. Preserve successive masters, revisions and rollback reasons. Add Code engineering only when programming use requires it.

Technical checks cover table structure, names, metadata, shaping, language coverage, contours, variable interpolation, constant cell widths, coding symbols and packaging. Run FontBakery universal/googlefonts/adobefonts, OTS and the available Font Validator. Test actual applications and use visual inspectors as supplementary inspection tools. Automated validity is not proof of readable or distinctive design.

Independent review identified tiny semicolon dot discrepancies, glyph contacts, operator stroke questions, metadata conventions and tool limitations. Accepted point fixes and rollback decisions remain reflected in the shipped drawings. Owner-approved exceptions preserve the original raw negative reports; catalog-specific requirements do not redefine private corporate-use acceptance.

The initial OFL edition changed only legal metadata and version identifiers. Those comparison reports remain historical evidence. Later RFN releases repair the Sans a junction, Ъ/ъ in all three families, and numeric contours. Original frozen final masters are changed only in the selected glyphs, and matching compatible masters supply only those outlines/variation tuples to the final VF files. Advances and layout remain unchanged. Changed TTF glyph programs are rehinted with the original tool options; unrelated glyph programs and common hint tables are preserved. Changed CFF charstrings are regenerated from raw glyph coordinates to avoid automatic LSB alignment shifts; the selected regenerated CFF programs omit the earlier per-glyph hint programs.

Astra reviews independently inspect complete file sets, intermediate weights and small text. Their scoped findings remain visible, including a tiny residual bend in Sans italic VF and the distinction between pre-rounding fit error and actual binary contours. All final technical validators are rerun; raw negative outcomes retain their actual statuses. See checks/SUMMARY.json for current results and checks/EVIDENCE-STAGES.md to distinguish earlier metadata checks from current drawing checks.

See FONT-SHA256.json for current fonts, checks/license-regression.json and checks/source-license-regression.json for preparation, checks/astra-independent-audit.json for independent evidence, and checks/fontvalidator-regression.json for exact error-record comparison. The original reference fonts, remote installation helpers and private infrastructure details are excluded from this public snapshot.

For the numeric revision, inspect every numeral together at a shared baseline and at 14/16pt, then enlarge suspect joins to 300/600pt. A closed contour can still contain an exposed stroke cap or an uneven counter. Join the original paths before expanding their strokes; align flat numeral terminals separately from optical overshoots. Preserve each 8 counter when uniting its bowls. Fit high-resolution original numeric geometry to compatible quadratic curves before final rounding, so static and variable deliveries use the same shapes. The scoped `SAB-Modul-1.0/source/repair_digits.py` rebuilds only the declared numeric targets from frozen final masters. It is a release repair operation, run once on a disposable copy, not a substitute for a complete clean rebuild of all historical source stages. The old accepted advances and layout remain frozen; derived hhea bearing extrema may change with the corrected bounds, while line metrics do not.
