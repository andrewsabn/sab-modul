# SAB Modul

**Корпоративное семейство шрифтов компании [FlyOptima.com](https://flyoptima.com/) и авторской страницы [sabynin.com](https://sabynin.com/).** Автор - Андрей Сабынин. Семейство создано с помощью Codex для сайта, презентаций, кода и других корпоративных материалов.

Репозиторий содержит готовые шрифты, собственные исходники и мастера, методологию, отчеты проверок и запрос, с которым можно пройти похожий путь для своей компании.

## Семейства

| Семейство | Назначение | Статические TTF | Внутренняя версия OFL |
|---|---|---:|---|
| SAB Modul Sans | Основной текст, заголовки и интерфейсы | 14 | 1.101 |
| SAB Modul Mono | Числа, таблицы и технические материалы | 14 | 1.101 |
| SAB Modul Code | Программирование и терминалы | 10 | 1.002 |

Для установки подготовлено 38 статических начертаний. Полная поставка содержит 154 файла в форматах TTF, OTF, VF и WOFF2, включая веб-подмножества. В исходниках сохранены 202 файла мастеров и промежуточных версий.

## Скачать и использовать

[Скачать полный архив](https://github.com/andrewsabn/sab-modul/releases/latest/download/SAB-Modul-OFL.zip). Архив содержит шрифты, исходники, лицензию и отчеты. [Пример подключения](demo.html).

Для установки выбирайте TTF или вариативную версию одной семьи. Одновременная установка статических и вариативных файлов с одинаковыми внутренними именами может создать конфликт. Для редактора и терминала выберите SAB Modul Code.

Для сайта используйте [Sans/Mono CSS](SAB-Modul-1.0/WEB/fonts.css) и [Code CSS](SAB-Modul-Code/code.css), сохраняя относительные пути к файлам. [Подробная инструкция](docs/RELEASE-DETAILS.md).

## Как создать свой шрифт

[Готовый запрос для Codex](docs/CREATE-YOUR-OWN-FONT-PROMPT.md) включает выбор концепции, работу с обычным текстом, жирностями и курсивом, контрольный лист А4, матрицу проверок и независимые отзывы. Его можно скопировать и адаптировать под бренд, языки и места использования. Он не обещает одинаковый срок, стоимость или художественный результат.

[Методология](METHODOLOGY.md) описывает подход к созданию и проверке. [Решения и ограничения приемки](ACCEPTANCE.md) объясняют, почему исходный отрицательный результат проверки нельзя заменять словом PASS.

## Проверки этой поставки

OTS прошли все 154 поставляемых файла. FontBakery выполнен с профилями universal, googlefonts и adobefonts: 27 запусков. Font Validator сформировал 154 отчета. Астра независимо сравнила все 356 поставляемых и исходных шрифтов; рисунок, метрики и функции при переходе на OFL сохранились.

Исходные результаты FontBakery содержат 302 FAIL и 44 ERROR. Font Validator содержит 6 183 E, полностью совпадающих с принятой базой. Отчеты и объяснения опубликованы без подмены статусов. Это поставка для прежнего корпоративного RU/EN применения с документированными ограничениями; полного соответствия каталогу Google Fonts она не заявляет.

Расширенное языковое покрытие неполное. После смены лицензии не повторены все сеансы визуальных инспекторов и полная сборка рисунка из исходников. Финализация OFL проверена на побайтную идемпотентность. Пример веб-подключения проверен в браузере без подмены шрифтов в осмотренных фрагментах.
