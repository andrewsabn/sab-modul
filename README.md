# SAB Modul

**Корпоративное семейство шрифтов компании [FlyOptima.com](https://flyoptima.com/) и авторской страницы [sabynin.com](https://sabynin.com/).** Автор - Андрей Сабынин. Семейство создано с помощью Codex для сайта, презентаций, кода и других корпоративных материалов.

Репозиторий содержит готовые шрифты, собственные исходники и мастера, методологию, отчеты проверок и запрос, с которым можно пройти похожий путь для своей компании.

## Семейства

| Семейство | Назначение | Статические TTF | Внутренняя версия OFL |
|---|---|---:|---|
| SAB Modul Sans | Основной текст, заголовки и интерфейсы | 14 | 1.102 |
| SAB Modul Mono | Числа, таблицы и технические материалы | 14 | 1.102 |
| SAB Modul Code | Программирование и терминалы | 10 | 1.003 |

Для установки подготовлено 38 статических начертаний. Полная поставка содержит 154 файла в форматах TTF, OTF, VF и WOFF2, включая веб-подмножества. В исходниках сохранены 202 файла мастеров и промежуточных версий.

## Скачать и использовать

[Скачать полный архив](https://github.com/andrewsabn/sab-modul/releases/latest/download/SAB-Modul-OFL.zip). Архив содержит шрифты, исходники, лицензию и отчеты. [Пример подключения](demo.html).

Для установки выбирайте TTF или вариативную версию одной семьи. Одновременная установка статических и вариативных файлов с одинаковыми внутренними именами может создать конфликт. Для редактора и терминала выберите SAB Modul Code.

Для сайта используйте [Sans/Mono CSS](SAB-Modul-1.0/WEB/fonts.css) и [Code CSS](SAB-Modul-Code/code.css), сохраняя относительные пути к файлам. [Подробная инструкция](docs/RELEASE-DETAILS.md).

## Как создать свой шрифт

[Готовый запрос для Codex](font-creation-prompt.md) включает выбор концепции, работу с обычным текстом, жирностями и курсивом, контрольный лист А4, матрицу проверок и независимые отзывы. Его можно скопировать и адаптировать под бренд, языки и места использования. Он не обещает одинаковый срок, стоимость или художественный результат.

[Методология](METHODOLOGY.md) описывает подход к созданию и проверке. [Решения и ограничения приемки](ACCEPTANCE.md) объясняют, почему исходный отрицательный результат проверки нельзя заменять словом PASS.

## Что исправлено в этом выпуске

У Sans устранен уступ на стыке верхней дуги и стойки у `а/a` и производных форм. Во всех Sans, Mono и Code удлинены флажки у «ъ» и «Ъ». Ширины символов, колонки кода и таблицы раскладки сохранены. Веб-файлы и исходные мастера обновлены.

[Образцы «а» при 300/600 pt](checks/a-junction/README.md) · [«ъ/Ъ» во всех начертаниях при 14/16 pt](checks/hard-sign/README.md) · [Веб-образцы](checks/hard-sign/web-proof.html).

## Проверки этой поставки

Текущие числа и файлы собраны в [checks/SUMMARY.json](checks/SUMMARY.json). OTS проверяет все 154 поставляемых файла. FontBakery выполнен с профилями universal, googlefonts и adobefonts для всех групп TTF/OTF/VF. Font Validator проверен без тестов растеризации. Исходные отрицательные результаты сохранены; исключения описаны в [ACCEPTANCE.md](ACCEPTANCE.md).

Астра отдельно проверила переход лицензии и исправление «а», затем изменение «ъ/Ъ». В последнем сравнении 356 файлов посторонние глифы, метрики, колонки, таблицы раскладки и вариации сохранились. Она проверила 8 224 геометрических случая и приняла рисунок «ъ/Ъ» в показанных условиях. Основные измерения стыка «а» охватили 56 250 случаев, флажка «ъ/Ъ» - 52 272 случая.

Есть ограничения. У наклонного Sans VF остался небольшой изгиб стойки «а» до 1,018 единицы при весе 700; прежней горизонтальной полки нет. Числа ошибки fit до округления не являются пределом ошибки готовых контуров. Расширенное языковое покрытие неполное. Полного соответствия каталогу Google Fonts этот выпуск не заявляет; сохранение RFN также требует отдельного учета при каталожной приемке. Прежние исключения Font Validator и требования каталога нельзя называть общим PASS.

Лицензия и RFN проверены внутри всех 356 поставляемых и исходных файлов. Финализация метаданных побайтно идемпотентна. В браузере проверены все 38 веб-начертаний на нужных словах без подмены шрифта. Полная сборка всех рисунков с нуля и все прежние сеансы графических инспекторов повторно не выполнялись. Точечные пересборки затронутых форм выполнены; условия и пределы каждого отчета указаны отдельно.
