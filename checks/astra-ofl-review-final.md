# Независимое итоговое ревью SAB Modul OFL

Проверка выполнена 2026-10-13 для `SAB-Modul-OFL`. Это повтор после исправлений упаковки. Файлы шрифтов и исходные программы не редактировались; проверки, требующие записи, выполнялись на временных копиях вне поставки.

## Вывод

Переход на OFL 1.1 подтверждён без изменения принятого рисунка, метрик, инструкций, OpenType-функций и вариаций. Новых блокирующих ошибок самих шрифтов не обнаружено. Комплект пригоден для продолжения прежнего русского/английского корпоративного применения в пределах ранее принятого рисунка. Этот вывод основан на полной регрессии двоичных данных и свежих технических проверках; новая визуальная приёмка во всех приложениях не заявляется.

Результат следует обозначать **RECHECKED_WITH_DOCUMENTED_LIMITATIONS**, а не чистый PASS всех валидаторов. FontBakery сохраняет 302 FAIL и 44 ERROR, Font Validator сохраняет 6183 E. Полное расширенное языковое покрытие и готовность к каталогу Google Fonts не подтверждены.

## Что проверено независимо

1. Все 154 поставляемых шрифта и 202 исходных мастера повторно сравнены с принятыми базами. Входные и выходные SHA совпали с отчётами, все 154 записи `FONT-SHA256.json` совпали с файлами. Таблицы вне `name`, `head`, `CFF ` идентичны побайтно. В `head` изменились только версия и контрольная сумма. Имена вне nameID0/3/5/13/14 сохранены. Полный декомпилированный CFF совпал после нормализации только `Notice`, `Copyright` и `version`, включая данные, которые не покрывает простая сверка CharStrings.
2. У всех 356 шрифтов согласованы версии, copyright, описание OFL и URL лицензии. `OS/2.fsType=0`. Версии готовых Sans/Mono равны 1.101, Code равна 1.002. Пять текстовых экземпляров OFL совпали побайтно. Отдельные Reserved Font Names не объявлены. Текст сверялся с [официальным OFL 1.1](https://openfontlicense.org/open-font-license-official-text/).
3. Повторная финализация OFL на копиях всех 356 шрифтов не изменила ни одного байта. Идемпотентность доказана запуском, а не только чтением программы.
4. Все 126 полных поставляемых файлов вне `WEB` содержат русский алфавит, включая Ё/ё, английский алфавит и цифры. У веб-подмножеств специально ограниченное покрытие; их нужно подключать согласно CSS.
5. Свежие результаты OTS содержат 154 кода 0 и совпадающие текущие SHA. Все 27 запусков FontBakery завершены, незавершённых проверок в итоговых счётчиках нет.
6. Все сообщения E в 154 свежих XML Font Validator сопоставлены с прежними полными XML по файлу и полному набору атрибутов. Различий нет. Для Sans/Mono использован старый `checks/fontvalidator`, а не частичный исторический `fontvalidator-license`. Для Code использован `checks/release-1.0.1-r2/fontvalidator`.

Независимые результаты сохранены вне публичной поставки в `astra-independent-audit.json`, `astra-validator-regression.json` и `astra-idempotence.json` рядом с этим отчётом.

| shape_languages | 60 | Реальные пропуски расширенных языковых наборов Sans/Mono |

| weightclass | 8 | Название Thin при принятом весе 200 не соответствует ожидаемому каталогом обозначению |

Итого 302 FAIL. Все 44 ERROR относятся к внешнему `fontdata_namecheck`, который завершился `KeyError: 'data'` в Code universal/googlefonts. Текущие логи не устанавливают HTTP429 как причину. Проверка внешнего имени остаётся незавершённой, а не пройденной.

По семействам результат составляет 118 FAIL Sans, 118 FAIL Mono и 66 FAIL Code. Профили Adobe не содержат FAIL/ERROR. Все результаты также содержат 797 WARN. Эти предупреждения нельзя обобщать как «всё исправлено», но перенос лицензии не изменил таблицы, к которым они относятся. Среди предупреждений есть рекомендации к моноширинным метрикам, контурам, комбинируемым знакам, avar и каталоговым метаданным.

### Ограничения языкового покрытия

`shape_languages` отмечает следующие обязательные пропуски Sans/Mono.

- Украинский набор не содержит U+02BC ʼ.
- Таджикский набор не содержит ҳ, ӯ, ӣ, ҷ.
- Узбекский кириллический набор не содержит ҳ.
- Туркменский кириллический набор не содержит Җ, җ.

Это реальные отсутствующие символы, а не ложные срабатывания валидатора. Побайтное совпадение `cmap` с принятой базой доказывает, что пропуски не возникли при OFL-подготовке. Оно не превращает недостаточное покрытие в полное.

Обязательных русских/английских ошибок в этих результатах нет. Для английского во всех семействах остаётся WARN об отсутствующем вспомогательном U+02BB ʻ. Редкие имена, заимствования и тексты с этим знаком требуют резервного шрифта либо отдельно согласованного расширения. Code не имеет этих 60 FAIL расширенного покрытия, но это само по себе не подтверждает полную визуальную приёмку каждого языка.

| Code | E4100 | 1320 | Прежний ошибочный разбор NULL Mark2Anchor |

| Code | E5201/E5202 | 462 | Прежний разбор VariationIndex |

Итого 4041 E Sans/Mono и 2142 E Code. Набор каждого файла совпал полностью; таблицы GPOS/GDEF/OS2 и контуры также не изменились. Поэтому применим прежний адресный разбор этих случаев. Это не общее разрешение пересечений, не новый полный анализ геометрии на всей оси и не сырой PASS. Растровые тесты Font Validator не выполнялись.

Современная спецификация определяет [NULL Mark2Anchor](https://learn.microsoft.com/en-us/typography/opentype/spec/gpos#mark2-array-table), [VariationIndex](https://learn.microsoft.com/en-us/typography/opentype/spec/chapter2#variationindex-tables) и [USE_TYPO_METRICS](https://learn.microsoft.com/en-us/typography/opentype/spec/os2#fsselection). Их наличие само по себе не является повреждением. В данном ревью применимость прежних исключений подтверждена точным совпадением файловых данных и полных сообщений, а не только совпадением общих чисел.

## Упаковка, происхождение и воспроизводимость

Прежние P1 о приватных путях/SSH-настройках и P2 о ложной частной лицензии устранены. В списке очистки перечислены 13 удалённых рабочих помощников, требовавших частной инфраструктуры или эталонов. Поиск по текстовым исходникам и отчётам больше не выявил домашних путей `/Users/`, OneDrive, прежнего удалённого адреса или ключей. Сторонних шрифтов среди 356 проверяемых файлов нет; все исходные двоичные мастера связаны с прежними SAB-исходниками по SHA. Само сравнение не доказывает мировую уникальность рисунка и не заменяет авторскую цепочку документов.

`REBUILD.md` теперь честно отделяет повторяемую финализацию метаданных от не повторённой полной сборки рисунка. Найденная при повторном ревью ошибка команд исправлена; вызовы используют `--revision`. Текущий манифест источников исключает собственную запись, все 372 проверенные SHA совпали. Исторический манифест отдельно помечен как исторический. Дополнительные локальные пути некоторых рабочих программ не составляют переносимую полную сборку; текущая инструкция её и не обещает.

Для сторонних шаблонов отчётов добавлены `licenses/FontValidator-MIT.md` и `licenses/FontBakery-Apache-2.0.txt`. Лицензии шрифтов и собственного шрифтового исходника остаются OFL; сторонние шаблоны и программные компоненты сохраняют свои лицензии. [Font Validator распространяется с MIT notice](https://raw.githubusercontent.com/HinTak/Font-Validator/FontVal-2.1.6/License.md).

Прочитанные README, METHODOLOGY и checks/SUMMARY.json отражают сырые отрицательные результаты, предел RU/EN, отсутствие повторной GUI-проверки и полной сборки рисунка. Существенного завышения статуса приёмки в этих формулировках не найдено.

## Финальная проверка упаковки

Технические входные шрифты Font Validator удалены после сохранения отчётов. Итоговый независимый инвентаризатор перечислил ровно 356 файлов шрифтов, дополнительных файлов вне двух регрессионных списков нет. Раннее число 226 включало 154 каталога с расширениями шрифтов и 72 реальных временных файла; счётчик исправлен проверкой `is_file()`. Этот ранний результат не используется для приёмки.

Риск чтения старых результатов повторного QA устранён. Публичный `tools/run_checks.py` удаляет ожидаемые XML/HTML Font Validator и JSON/HTML FontBakery перед соответствующими заданиями. README включает применение проверенного исправления CFF перед повтором FontBakery в отдельном окружении.

Последняя сверка подтвердила отсутствие личных путей и ключей в текстовой поставке, совпадение обеих сторонних лицензий с исходными пакетами и точное соответствие `checks/SUMMARY.json` сумме 27 сырых JSON FontBakery. Для README переданы две небольшие поправки ссылок на инструкции семейств; для METHODOLOGY уточнено, что полное совпадение исторических сообщений относится именно к Font Validator.

Окончательный архив и его общий SHA-256 этим отчётом не проверены, поскольку упаковка выполняется после независимого отзыва. Это оставшаяся проверка доставки, а не открытая ошибка шрифтов. Вывод о сохранности 356 шрифтов и переносе прежнего RU/EN применения подтверждён перечисленными проверками.
